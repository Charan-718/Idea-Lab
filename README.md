# Idea-Lab

Exploratory analysis of battery electrochemical impedance spectroscopy (EIS) data. The notebooks load complex impedance measurements, derive impedance features, visualize spectra, and experiment with filtering, clustering, and distribution-of-relaxation-times (DRT) analysis.

## Project Contents

### Notebooks

- `EIS_data.ipynb` loads `EIS_Bat12.csv`, converts values to complex numbers, applies an exponential low-pass filter, plots Nyquist spectra, explores short-time Fourier transforms and peak features, and demonstrates K-means clustering and DRT analysis.
- `EIS_data_new.ipynb` estimates frequency from the imaginary impedance, plots Nyquist and Bode views, and compares filtered and unfiltered impedance data.
- `SOC_process.ipynb` converts impedance data into frequency and magnitude matrices, plots Nyquist spectra, and applies Savitzky-Golay smoothing.
- `Battery02.ipynb` explores signal processing of filtered EIS spectra, including STFT.

### Data and generated artifacts

- `EIS_Bat12.csv` is a headerless matrix of complex impedance measurements. The checked-in matrix contains 14 spectra with 10 values per spectrum.
- `BatteryID02.csv` is a long-form dataset with `MEASURE_ID`, `SOC`, `BATTERY_ID`, `FREQUENCY_ID`, and complex `IMPEDANCE_VALUE` columns.
- `EIS_Bat12_Frequency_Matrix.csv` and `EIS_Bat12_Magnitude_Matrix.csv` contain derived frequency and impedance-magnitude values.
- `EIS_Bat12_with_Estimated_Frequency.csv`, `EIS_Bat12_with_Bode.csv`, and `EIS_Bat12_with_Bode_Filtered.csv` contain derived impedance, frequency, magnitude, phase, and/or filtered values.
- `DRT_EIS_Combined_Features.csv` contains extracted DRT and impedance features.
- `filtered_data.pkl` is a serialized filtered-data artifact produced by notebook workflows. Pickle files should only be loaded from trusted sources.
- `research-files/EIS_Bat12.csv` is an additional copy of the EIS input. `impedance.csv` and `frequencies.csv` are also included as supporting data files.

Some notebooks write generated files into the current working directory. Run them from the repository root if you want outputs alongside the checked-in data.

## Setup

Use a local Python 3 environment. The checked-in `env/` directory contains a Windows-specific environment and is not portable to macOS or Linux; create a fresh environment instead.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas scipy matplotlib seaborn scikit-learn statsmodels jupyter
jupyter notebook
```

Open the notebook you want to run from the Jupyter file browser. Run cells in order; notebooks may depend on files generated by earlier cells or another notebook.

## Analysis Notes

- The notebooks are research and analysis prototypes, not a packaged application or a validated battery state-of-charge or state-of-health predictor. No automated test suite or canonical end-to-end pipeline is included.
- Frequency estimates use the capacitive-reactance relationship $f = 1/(2\pi |\operatorname{Im}(Z)| C)$ with an assumed capacitance of `1.042e-6` F. Treat these values as estimates, not instrument-measured frequencies.
- Some feature extraction uses a generated logarithmic frequency axis. The Granger-causality example creates a random defect indicator, and the DRT example uses simulated frequency inputs. These examples are illustrative and are not evidence of measured degradation or validated DRT results.
- Filtering parameters, row/column selection, and assumptions are defined in the individual notebooks. Review them before interpreting or reusing derived data.

## Data Provenance

The repository includes research-paper PDFs alongside the datasets. Consult the relevant source publication and dataset documentation for measurement conditions, units, and provenance before using the data for scientific conclusions.
